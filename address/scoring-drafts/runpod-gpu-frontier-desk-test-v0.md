## 「フロンティアモデル級」の定義（この表用）

| 記号 | 意味 |
|---|---|
| **F★** | 閉源トップAPI並みを**その1枚だけで**恒常運用 → 原則不可（単カードでは非現実） |
| **F1** | オープン準フロンティア（例: 70B級Q4をVRAM内で実用速度、または大容量で高品質量子化） |
| **F2** | 強いローカルだがフロンティア未満（34B〜、70Bはオフロードで遅い等） |
| **F0-GSM** | GSM最小単位（U1–U6向け 7B–14B級）は十分 |

判定列「フロンティア級？」は **F1以上を△〜○、F★を単カードで期待しない**。

目安メモリ（概数）:
- 70B Q4: ~40–48GB VRAM（KV込みで余裕欲しい）
- 70B FP8/高品質: ~80GB+
- 405B / 巨大MoE全載せ: 多枚 or 巨大HBM。単カード不可が普通

## 総回答

**「リストの全GPUでフロンティアモデル級は可能か？」→ No（全部では不可能）。**

- **F★（閉源トップと同等を1枚で）**: どのカードも「可能」とは言わない  
- **F1（オープン準フロンティア）**: だいたい **48GB以上で△〜○、80GB以上で○、141GB以上で余裕○**  
- **24–32GB**: 準フロンティアは基本不可。GSMや中規模は可  
- **GSM U1–U6の最小単位**: **全GPUで可能**（7–14B級）

## GSM実験のおすすめ（コスパ）
1. まず: **RTX 4090 / 5090 / A40** で分類機＋最小単位の測り方確立（安）  
2. 準フロンティア比較: **L40S / RTX 6000 Ada / RTX Pro 6000**  
3. 本気の大モデル: **H200(水200) / B200 / B300**（高い）
