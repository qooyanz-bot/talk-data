# 複数GPUでChatGPT級（F★）机上テスト v0

日付: 2026-09-05 / **実デプロイなし**
価格: ユーザー提示の RunPod 単価（1枚あたり）。マルチは単純掛け算（ノード割増・通信・空き無しは未算入）。

## 定義
- **F★目標**: 閉源ChatGPT級に「近づける／一部タスクで並ぶ」オープン大モデルを、複数枚で載せられるか
- **品質の注意**: 枚数を足しても **ChatGPTそのものにはならない**。到達するのは主に Llama 405B 級・DeepSeek-V3/R1 671B級などの **オープン最上位帯**
- 判定: メモリが足りるか（重み+余裕）。速度・相互接続は別途

### C. 非推奨（複数でもF★机上×）

| 構成 | 理由 |
|---|---|
| 24GB × N（4090等） | 枚数を増やせば理論上容量は足せるが、相互接続・レイテンシ・運用が地獄。F★机上は実質× |
| 5090 32GB ×少数 | 同上。実験用GSM向き |
| 単カード全機種 | 前回どおり F★× |

## 総合判定

1. **複数枚なら「オープン最上位を載せる」机上は可能**（特に H200×8、H100×16、B200/B300複数）。
2. **それでChatGPT級が保証されるか → 保証しない。** 近づく候補を走らせられる、まで。
3. **コスパ（メモリ到達）**: A100×16が安めだが遅い。H200×8が「大MoEの定石」。B300×4は枚数少ない代わり単価高い。
4. **GSM戦略**（分類＋小モデル）は別ルートで、$/hは桁違いに安いが F★置換ではない。

## 失敗条件（この机上の限界）
- RunPodで同型を同時に8–16枚確保できるとは限らない
- ノード間通信品質未検証
- 量子化で「級」が落ちる可能性
- 閉源ChatGPTの学習データ・ツール生態はコピー不能
