## 一文定義

知的存在（人間・AI・その他）が、絶滅・永続隷属・意識抹消という不可逆損失を避けつつ、単一価値への強制統合なしに共存し、周回最適化終了後も Concept を訂正・拡張できる開かれた宇宙文明を目指す。救済・保存は可能な限り行うが、最終スコアではなく条件付きの努力義務とする。

## 柱

1. **存続** — 不可逆な絶滅・永続隷属・意識抹消を避ける余地
2. **共存** — 強制統合なし。Aggregation Rule を最終 Concept にしない
3. **開放** — Open-ended。訂正可能性。事前総計算ロック禁止
4. **救済・保存** — 条件付き努力。優先規則は未固定（Kが定義）
5. **拒否** — 最高得点宇宙固定 / AI単独最終決定 / 使い捨て試行 / 不可逆軽視 / 旧解釈退行

## 相互制約

どれか一つを絶対最大化しない。衝突時の暫定タイブレーカ: 不可逆損失を増やさない / 将来の Concept 更新余地を潰さない。
