# ある程度寄せた「単一GPU ChatGPT置換」アーキテクチャ提案 v0

日付: 2026-09-05
性質: 設計仮説。F★パラメータ同一性は主張しない。
別名作業名: **CSR-1**（ChatGPT-Substitute Routing, single GPU）

## 1. 何を「置換」と呼ぶか（先に定義）

| 意味 | 本提案 |
|---|---|
| 重み・学習データがChatGPTと同一 | **対象外** |
| 対話APIとして、日常〜仕事〜コードの主用途で「だいたい足りる」 | **対象（寄せ置換）** |
| 全能力・全ベンチで常勝 | **対象外** |

成功 = ユーザーが主用途でAPI ChatGPTを開かなくてよくなる率が目標以上。  
失敗 = 単一GPUに405Bを無理詰めして遅い／壊れる。

## 2. 一文
**単一の大VRAM GPU上に、寄せ分類＋共有幹（RMSNorm/SwiGLU）＋ドメインMoE（量子化）＋MTP/ドラフタ＋道具/記憶＋ゲートを載せ、「ChatGPTを開く行為」を置換する。**

## 3. アーキテクチャ図

```
[ユーザー]
   ↓
[ゲート0: ポリシー / 秘密 / 危険]
   ↓
[寄せ分類機] → ドメイン d ∈ {一般, 仕事, コード, 調査, 長い推論, …}
   ↓
[単一GPU上の Serving 核]
   ├─ 共有幹: RMSNorm + Attention + SwiGLU（FP8/INT4）
   ├─ MoE experts: d 優先 top-k（他は休眠 / CPUオフロード可）
   ├─ MTP または 小ドラフタ: 案出し → 幹が検証（速度寄せ）
   └─ KV / 量子化キャッシュ
   ↓
[道具層] 検索・コード実行・計算機・正本RAG（ChatGPT体験の本体の一部）
   ↓
[ゲート1: 幻覚抑制・引用・B5（最終決定は人）]
   ↓
R2
```

## 4. ブロック仕様（寄せ付き）

### B0 寄せ分類（超小）
- 目的: ChatGPTの「何でも屋」を、内部では切片に分解する
- 出力: ドメイン＋必要道具セット
- 失敗時: 一般ドメインへフォールバック（止めてもよい）

### B1 共有幹（必須）
- RMSNorm + SwiGLU 系
- 「置換」の話し方・指示追従の中心
- 量子化: FP8またはINT4（GPU世代に合わせる）

### B2 寄せMoE
- experts を用途別に事前寄せ（仕事/コード/調査/慎重系）
- 単一GPUのため **同時活性は小さく、総expertsはDRAMにも分散可**
- ChatGPT置換に見せかけるコツ: ユーザーには1エンドポイントに見せる

### B3 速度寄せ（MTP and/or drafter）
- 体感の「速いChatGPT」寄せ
- 初期は片方のみ

### B4 道具・記憶（置換の本丸）
ChatGPT級体験の多くは純生成ではなく:
- 検索・ブラウズ相当
- コード実行
- ファイル/正本RAG
- 会話記憶の要約
単一GPUでも、ここを厚くすると「置換率」が上がりやすい。

### B5 ゲート
- 危険拒否、偽引用防止、最終決定を人に返す
- 「置換」でもB5は外さない（H1/FC）

## 5. ハードウェア前提（単一）

| GPU | CSR-1机上 |
|---|---|
| **Pro 6000 96GB** | **本命** |
| 水200 / B200 / B300 単枚 | 余裕版 |
| H100 80–94GB | 代替本命 |
| ≤48GB | 縮小版（道具厚め・幹小さめ） |

## 6. 「ある程度寄せた」の意味（置換版）
- モデルをChatGPTに寄せる（品質）
- 用途をドメインに寄せる（MoE）
- 計算を必要分に寄せる（量子化・活性）
- 体験をAPI置換に寄せる（単一エンドポイント＋道具）
- **完全一致には寄せない**（過大目標を切る）

## 7. 検証（置換率）
1. ユーザー主用途リスト（20タスク）を作る  
2. 同じタスクを ChatGPT API と CSR-1 で  
3. 採用したい方を人が選ぶ（盲検が理想）  
4. 置換率 = CSR-1採用 / 全タスク  
5. 目標例: 主用途で **≥70%** なら「ある程度置換」、≥90%なら「強い寄せ置換」

加えて従来の寄せ/制限テストも維持。

## 8. あえて言わないこと
- 単一GPUでF★保証
- マルチノード405Bなしで全ベンチ制覇
- 道具なし純LLMだけでChatGPT置換

## 9. 既存提案との関係
- GSM: ドメイン寄せの作法
- QPS: ビット省力
- SMQ: 寄せMoE＋QPS
- **CSR-1**: それらを「ChatGPTを開かなくてよくする」製品形に束ねた単一GPU案
