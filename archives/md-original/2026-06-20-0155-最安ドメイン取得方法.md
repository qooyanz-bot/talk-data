# パターン2：CLIだけで作成

認証

```bash
cloudflared tunnel login
```

Tunnel作成

```bash
cloudflared tunnel create devspace
```

DNS作成

```bash
cloudflared tunnel route dns devspace app.example.com
```

設定ファイル

```yaml
tunnel: TUNNEL_ID

ingress:
  - hostname: app.example.com
    service: http://localhost:3000

  - service: http_status:404
```

起動

```bash
cloudflared tunnel run devspace
```

これで

```text
app.example.com
↓
Cloudflare
↓
Tunnel
↓
localhost:3000
```

になります。citeturn0search5turn0search11turn0search16
