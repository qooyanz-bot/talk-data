```
Create a clean, practical SaaS product interface concept for “KijiPort”, an AI content CMS for creators.

The product helps users manage ideas, write articles, generate platform-specific images, schedule posts, and analyze performance across note, X, Threads, YouTube, Substack, Medium, and Hashnode.

Design style:
- calm professional SaaS dashboard
- content management system feel
- editorial workspace
- not futuristic, not flashy
- high usability
- clean typography
- dense but readable information
- left sidebar navigation
- main workspace
- right-side inspector panel
- subtle neutral background
- restrained accent colors
- no decorative gradient blobs
- no marketing landing page
- no oversized hero section

Main screen content:
- Today’s content ideas
- Drafts in progress
- scheduled posts calendar
- platform performance overview
- AI agents status
- Skill improvement suggestions
- API usage indicator
- content pipeline from idea to post

Visual tone:
A serious but friendly workspace for solo creators and small teams.
It should feel like Notion, Linear, and a lightweight analytics dashboard combined, but with its own identity.

Avoid:
- overly colorful startup gradients
- fantasy AI visuals
- cluttered charts
- generic robot mascots
- stock-photo style imagery
- landing page composition

Output:
A polished high-fidelity web app dashboard mockup, desktop viewport, realistic SaaS UI, readable layout, refined spacing, practical product interface.
```
