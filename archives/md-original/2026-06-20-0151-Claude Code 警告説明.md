このメッセージは、Claude（Claude Code）の設定やプロジェクト読み込み時によく出る警告です。

> **"1 folders were skipped because it overlaps a protected location or is the home/root directory."**

日本語にすると、

> **「1つのフォルダは、保護された場所と重複しているか、ホームディレクトリ（またはルートディレクトリ）そのものだったため、読み込み対象から除外しました。」**

という意味です。

### よくある原因

#### ① C:\ を指定した
例えば

```text
C:\
```

や

```text
D:\
```

をプロジェクトフォルダとして追加した場合。

Claude CodeはPC全体を読ませることを防ぐために拒否します。

---

#### ② ユーザーフォルダ全体を指定した

例えば

```text
C:\Users\あなた
```

や

```text
C:\Users
```

を指定した場合。

これも保護対象なのでスキップされます。

---

#### ③ OneDriveのルートを指定した

例えば

```text
C:\Users\xxx\OneDrive
```

など。

大量の個人ファイルがあるため保護されることがあります。

---

#### ④ Claude設定フォルダ自身を指定した

例えば

```text
C:\Users\xxx\.claude
```

など。

システムフォルダ扱いで除外される場合があります。

---

### AI開発用ならこうする

おすすめは専用ディレクトリを作ることです。

```text
D:\AI
├─ projects
├─ skills
├─ templates
├─ notes
└─ sandbox
```

あるいは

```text
D:\Dev
├─ project-a
├─ project-b
└─ project-c
```

そして Claude Code には

```text
D:\Dev\project-a
```

のような**個別プロジェクトフォルダ**を開かせます。

---

### 確認したいこと

どのフォルダをClaudeに追加しようとしたのか教えてください。

例えば

```text
C:\Users\Noriaki
```

や

```text
D:\AI
```

のようなパスが分かれば、

- なぜ警告が出たのか
- Claude Code向けにどう整理すべきか
- Codexと共用するならどう構成するか

まで具体的にアドバイスできます。
