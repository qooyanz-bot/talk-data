## 1. 必要な準備
1. **Pythonのインストール**  
   Python3 が必要です（`python --version` で確認）。  

2. **必要なライブラリのインストール**  
   ```bash
   pip install schedule
   ```

   - `smtplib`: Python標準ライブラリ（メール送信）
   - `email`: Python標準ライブラリ（メール作成）
   - `schedule`: 定期実行ライブラリ  

3. **Gmailの場合の設定**  
   - 「2段階認証プロセス」を有効化
   - 「アプリパスワード」を発行  
   （これを通常のパスワードの代わりに使用）

---

## 2. サンプルスクリプト

```python
import smtplib
from email.mime.text import MIMEText
from email.utils import formatdate
import schedule
import time

# 設定部分
SMTP_SERVER = "smtp.gmail.com"
SMTP_PORT = 587
FROM_EMAIL = "あなたのメールアドレス@gmail.com"
APP_PASSWORD = "アプリパスワード"  # Gmailアプリパスワードを使用
TO_EMAIL = "送信先メールアドレス@example.com"

def create_message():
    # 日報の内容（ここを動的に生成してもOK）
    body = """\
【日報】
本日の業務内容:
- 顧客対応 3件
- 資料作成 2件

明日の予定:
- 打ち合わせ 10:00
"""
    msg = MIMEText(body, "plain", "utf-8")
    msg["Subject"] = "日報"
    msg["From"] = FROM_EMAIL
    msg["To"] = TO_EMAIL
    msg["Date"] = formatdate()
    return msg

def send_report():
    msg = create_message()
    try:
        with smtplib.SMTP(SMTP_SERVER, SMTP_PORT) as server:
            server.starttls()
            server.login(FROM_EMAIL, APP_PASSWORD)
            server.send_message(msg)
        print("日報メールを送信しました。")
    except Exception as e:
        print("エラー:", e)

# 毎日18:00に実行する例
schedule.every().day.at("18:00").do(send_report)

print("日報メール自動送信スクリプトを開始しました。")
while True:
    schedule.run_pending()
    time.sleep(60)
```

---

## 3. 実行方法

1. 上記スクリプトを `daily_report.py` として保存  
2. 実行  
   ```bash
   python daily_report.py
   ```
3. バックグラウンドで動かす場合
   - Windows: タスクスケジューラに登録
   - Mac/Linux: `cron` に登録、または `nohup python daily_report.py &`

## 4. 応用例
- 日付を件名に入れる  
  ```python
  from datetime import datetime
  msg["Subject"] = f"日報 {datetime.now().strftime('%Y-%m-%d')}"
  ```
- ExcelやCSVから日報を自動生成  
- 複数人に送信する（`msg["To"]` にカンマ区切りでアドレスを入れる）
