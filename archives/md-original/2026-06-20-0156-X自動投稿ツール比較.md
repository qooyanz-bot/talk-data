## 実務目線の選び方

- **日本語でXを堅実に運用するなら：SocialDog**
  - 投稿予約、分析、フォロワー管理、RSS自動投稿まで一通り揃う。
  - 今の用途なら、最初に試すべき本命です。

- **X投稿の質、スレッド、個人ブランディングを磨くなら：Typefully**
  - 文章作成からスレッド設計、分析までがX中心で設計されています。

- **X・Threads・note・Instagramなどを横断するなら：Metricool**
  - 単体SNS用ツールを増やすより、投稿カレンダーと分析を集約した方が運用が崩れません。

- **AIやRSS、Notion、Google Sheetsと自動連携したいなら：n8n**
  - ただし、投稿の自動化よりも「下書き生成→人が承認→投稿」の設計にすべきです。

## 自動化で避けるべきこと

Xは、RSSなど外部情報を元にした自動投稿自体は認めています。ただし、重複投稿、無差別な返信・メンション、自動フォロー・解除、大量DMはスパム扱い・凍結対象になり得ます。特にキーワード監視からの自動返信は、相手の明確な同意やオプトアウトなしでは避けるべきです。 citeturn153247search0turn153247search2turn153247search4

率直に言うと、**自動投稿だけで伸ばそうとする運用は弱い**です。自動化すべきなのは投稿そのものではなく、ネタ収集・下書き化・投稿カレンダー・数値集計です。返信、引用、企画判断は人間が握った方がアカウントの価値が積み上がります。

X運用でいう4機能は、単なる「予約投稿」ではなく、**ネタを見つける → 投稿案に変える → 出す順番を決める → 結果から次を改善する**仕組みです。

## 1. ネタ収集

投稿の材料を集めて、後で使える状態にする機能です。

| 機能 | 具体例 | 向くツール |
|---|---|---|
| キーワード監視 | 「Claude Code」「Codex」「MCP」などを登録し、関連するX投稿を一覧で追う | SocialDog |
| 競合・類似アカウント監視 | 同ジャンルで伸びた投稿、反応の多い論点、頻出テーマを観察する | Metricool、X Pro、専用リスニング系 |
| RSS収集 | AIニュース、公式ブログ、GitHub Releases、note記事などを自動取得する | n8n |
| トレンド確認 | 検索量や急上昇テーマを確認し、投稿テーマの優先順位を決める | Google Trends |
| 保存・タグ付け | 見つけた投稿・記事を「記事ネタ」「引用候補」「反論ネタ」などで分類する | Notion、Google Sheets、Buffer Create |

SocialDogには、登録キーワードに関する投稿を継続収集する「キーワードモニター」系の機能があります。n8nならRSSの新着取得をトリガーにして、ニュースやブログを自動で集められます。 citeturn263722search0turn263722search20turn263722search30

**重要なのは、ネタを“保存”するだけで終わらせないことです。**  
最低でも次の項目を付けないと、後で投稿に変換できません。

- 元URL
- 何が起きたか
- 自分の意見・切り口
- 誰向けか
- 投稿形式：単発、スレッド、引用、画像付き
- 優先度
- ステータス

## 2. 下書き化

収集したネタを、実際に投稿できる文章に変える機能です。

| 機能 | 具体例 | 向くツール |
|---|---|---|
| AI下書き生成 | 記事URLや要点から、X投稿案を3〜5本作る | n8n＋LLM、Buffer、Metricool |
| リライト | 固い文章をX向けに短くする、強いフックを付ける | Typefully、Buffer |
| スレッド分割 | 長い解説を「1投稿目の結論→根拠→実例→CTA」に分解する | Typefully |
| プラットフォーム別変換 | 同じ素材をX、Threads、LinkedIn向けに書き分ける | Buffer、Metricool、Typefully |
| チーム承認 | 下書き→レビュー→承認済み→予約済み、という状態管理 | Metricool、Typefully、n8n＋Slack/Telegram |

TypefullyはX投稿・スレッドの下書き、予約、分析、共同編集に対応しています。Bufferはアイデアの整理、AIによる文章生成・リライト・媒体別の書き換えを打ち出しています。 citeturn263722search1turn263722search26turn268214search2turn268214search19

n8nでは、たとえば次のような流れが組めます。

```text
RSS / Google News / 保存したURL
↓
AIが要約・重要度判定
↓
「X投稿案3本」を生成
↓
Google Sheets / Notion に下書き保存
↓
Slack・Telegramで承認
↓
予約投稿ツールまたはXへ投稿
```

実際に、n8nにはRSSから記事を取得し、AIで投稿文を生成し、人間の承認後にSNS投稿するテンプレートがあります。 citeturn263722search39turn263722search28

## 3. 投稿カレンダー

「いつ、何を、どの媒体に出すか」を可視化・制御する機能です。

単なる日時指定ではなく、運用の渋滞を防ぐための仕組みです。

| 機能 | 具体例 |
|---|---|
| カレンダービュー | 週・月単位で投稿予定を表示する |
| キュー投稿 | 「平日8時」「平日12時」など、空き枠に自動投入する |
| 投稿ステータス管理 | ネタ → 下書き → レビュー中 → 承認済み → 予約済み → 投稿済み |
| 媒体別プレビュー | X、Threads、LinkedInで改行・文字数・画像を確認する |
| 投稿枠の偏り確認 | 同じ日に宣伝投稿ばかり集中していないかを見る |
| コンテンツ比率管理 | 例：ノウハウ50%、ニュース20%、意見20%、告知10% |

Metricoolは投稿計画、予約、分析、管理を一体化した設計で、PlannerではAI支援、編集、投稿前プレビューなどを提供しています。Typefullyも自然言語での予約や、アカウント単位で下書き・スケジュール・分析を分ける機能を持ちます。 citeturn263722search2turn263722search27turn263722search8turn263722search16

あなたのように、note記事、AIニュース、Claude/Codex系の解説を扱うなら、カレンダーはこう切るのが現実的です。

```text
月：今週の重要AIニュース
火：実務ノウハウ
水：失敗談・本音・反論
木：note記事の要点スレッド
金：ツール比較・テンプレート
土日：軽い意見、作業ログ、引用投稿
```

毎日ゼロから考える運用は、ほぼ確実に止まります。投稿カレンダーは投稿予約のためではなく、**意思決定を前倒しするため**のものです。

## 4. 数値集計・分析

「何投稿したか」ではなく、**どのテーマ・切り口・形式が結果につながったか**を判断する機能です。

| 指標 | 見る意味 |
|---|---|
| インプレッション | そもそも届いているか |
| エンゲージメント率 | 表示された人に内容が刺さったか |
| いいね・リポスト・返信・保存 | 共感、拡散、議論、実用性のどれが強いか |
| プロフィール遷移 | 投稿がアカウントへの関心に変わったか |
| URLクリック | note、商品、LPなど外部導線に送れたか |
| フォロー増減 | 投稿が長期的な読者獲得につながったか |
| 投稿時間別成果 | 自分の読者が反応しやすい時間帯 |
| テーマ別成果 | AIニュース、解説、比較、炎上寄り意見などの勝率 |

Typefullyは投稿・スレッドの分析を提供し、MetricoolはXを含むSNSのプロフィール、エンゲージメント、成長を横断分析する用途に対応しています。Bufferも到達・クリック・エンゲージメントなどの分析機能を案内しています。 citeturn263722search1turn263722search11turn263722search17turn268214search5

ただし、数字を眺めるだけでは無意味です。週1回、最低限この4つに集約してください。

```text
1. 一番伸びた投稿は何か
2. なぜ伸びたのか：テーマ、冒頭、形式、投稿時間
3. 一番外部クリックを生んだ投稿は何か
4. 来週、何を増やし、何をやめるか
```

## 現実的な構成

### 最小構成
- ネタ収集：X検索、Google Trends、RSS
- 下書き：ChatGPT / Claude
- カレンダー・予約：SocialDog または Typefully
- 数値集計：X標準分析＋投稿一覧をGoogle Sheetsへ記録

### 複数SNS運用
- ネタ収集：n8n＋RSS＋Google Sheets / Notion
- 下書き：n8n＋LLM
- カレンダー・予約：Metricool
- 分析：Metricool

### 自動化を本格化する構成
- 収集：n8nでRSS、ニュース、GitHub、Google Sheetsを統合
- 判定：AIに重要度・自分の発信テーマとの一致度を採点させる
- 下書き：X用に複数案を生成
- 承認：SlackまたはTelegram
- 投稿：予約ツールまたはX連携
- 計測：週次で投稿実績をSheetsへ蓄積

Xでは、キーワード検索を起点に不特定多数へ自動返信・自動メンションする運用は認められていません。自動化すべきなのは収集、要約、下書き、計測であり、返信や引用の最終判断は人間が持つべきです。 citeturn268214search1turn268214search4
