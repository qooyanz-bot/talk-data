はい、**Codex CLI内ならあります。**

使うべきコマンドは主にこれです。

```text
/usage
```

直接開くなら：

```text
/usage daily
/usage weekly
/usage cumulative
```

公式ドキュメント上でも、`/usage` は **アカウントのtoken使用量を見るコマンド**で、daily / weekly / cumulative の表示に対応しています。Codexサービスアカウント認証でログインしていない場合は、サインイン要求が出ます。citeturn282826view1

現在のセッション単位で見るなら：

```text
/status
```

これは **現在のモデル、承認設定、書き込み可能ディレクトリ、現在のtoken使用量、残りコンテキスト容量**を見る用途です。citeturn282826view0

さらに常時表示したいなら：

```text
/statusline
```

フッターに **context stats / rate limits / token counters** などを出せます。citeturn282826view1

整理すると：

| 見たいもの | コマンド |
|---|---|
| 今のセッションのtoken使用量 | `/status` |
| アカウント全体の使用量 | `/usage` |
| 今日の使用量 | `/usage daily` |
| 週間使用量 | `/usage weekly` |
| 累計使用量 | `/usage cumulative` |
| フッターに常時表示 | `/statusline` |

注意点として、**「あと何token使えるか」を完全にCLIだけで常に正確に見る**というより、`/usage` で使用状況、`/status` でセッション・コンテキスト状況を見る、という理解が正確です。

ChatGPTプラン側のクレジット残高や最近の利用状況は、WebまたはCodexアプリの **Codex Settings > Usage Dashboard** でも確認できます。citeturn504679view4

APIキー運用の場合は別で、OpenAI APIのUsage dashboard、またはAPIレスポンス内の `usage` キーでtoken使用量を確認します。citeturn981838view0
