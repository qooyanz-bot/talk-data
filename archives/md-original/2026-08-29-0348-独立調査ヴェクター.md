- temporal validity

- confidence
- stop / abstain condition
- fallback path
- estimated and measured cost

実行計画では、画素数だけでなく以下を分離して計測します。

- decoded pixels
- sentinel pixels
- detail ROI pixels
- memory bytes read / written
- memory bandwidth
- cache hit / miss
- branch count / branch misprediction
- model loading and initialization time
- model weight bytes loaded
- kernel launch and synchronization overhead
- queueing and scheduling overhead
- wall-clock latency
- peak memory
- energy, if measurable

W1/W2/W3、timing tolerance、negative control、
