# Remote Serverとは

これを勘違いする人が多いのですが、

**Coolifyを002や003へインストールするわけではありません。**

Coolifyが入るのは001だけです。

002・003は

- Docker
- SSH

だけ動いていれば十分です。

Coolifyが

```
SSH
    ↓
docker compose up
docker compose down
docker logs
docker exec
```

を自動で実行します。

つまり

```
Coolify
      ↓
SSH
      ↓
Docker
```

という構成です。

# この構成の利点

この分離によって、負荷の影響範囲が明確になります。

- **002で大量スクレイピングしてCPUが100%になっても、003のPostgreSQL性能は維持される。**
- **003でVACUUMやインデックス再構築を実行しても、002のWorkerは止まらない。**
- **001は管理専用なので、デプロイやログ閲覧が重くなりにくい。**

EnterpriseOSのように約500万社規模の企業データを扱い、スクレイピング・AI処理・データベースを同時に動かす構成では、この3台分離は運用・拡張・障害切り分けの面で合理的です。将来は002を複数台に増やしてWorkerだけを水平スケールさせることもできます。 memcite
