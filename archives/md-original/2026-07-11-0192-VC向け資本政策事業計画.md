# 売上の締め日・振込日

Stripeには**「月末締め・翌月払い」のような固定締め日はありません。**

日本では、売上ごとに一定期間経過後、設定したスケジュールに従って自動で振り込まれます。

一般的な設定は以下です。

| 項目 | 内容 |
|------|------|
| 初回振込 | アカウント開設直後は通常7〜14日程度保留されることがあります |
| その後 | 毎日・毎週・毎月から選択可能 |
| 振込手数料 | 無料 |
| 売上締め日 | なし（ローリング方式） |

例えば「毎週金曜日振込」に設定した場合は、その時点で入金可能になった残高がまとめて振り込まれます。citeturn0search3turn0search0

## 私なら、この資本政策を一部見直します

- VCからは**投資前（Pre-Money）に10〜15%程度のストックオプションプール確保**を求められることが多い。

- Seed後：約80〜85%

- Series B後：約35〜50%

程度になるシナリオも併記しておくと、投資家との議論に耐えやすくなります。
