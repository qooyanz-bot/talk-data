この設計は、**EnterpriseOSで利益を出す商品はSaaS（Company Growth）だけにし、ドメインは利益を乗せない「集客・契約促進」のための付加価値にする**という考え方です。

これはかなり良い戦略です。特にあなたが目指している「AI会社設立〜企業サイト〜CRM〜営業支援」の一気通貫サービスには合っています。

## 全体像

```
お客様

        ▼

Company Growth（月額9,800円）
        │
        ├─ AI企業サイト
        ├─ AI更新
        ├─ ホスティング
        ├─ CMS
        ├─ 問い合わせ
        └─ AIエージェント

        ▼

オプション

□ 独自ドメイン取得
```

ここで重要なのは、

**利益を取るのはCompany Growthだけ**

ということです。

## ドメインは原価販売

例えばOpenProviderから取得するとします。

|ドメイン|OpenProvider原価|
|---------|---------------|
|.com|約1,600円|
|.net|約1,800円|
|.jp|約3,200円|

EnterpriseOSでは

```
.com

1,600円

そのまま販売
```

になります。

つまり

```
仕入

1600円

↓

販売

1600円
```

利益ゼロです。

---

## なぜ利益ゼロにするのか

理由は3つあります。

### ① 比較されない

普通の制作会社

```
.com

3,980円
```

EnterpriseOS

```
.com

1,600円
```

となるので、

> 「この会社、ドメインで利益取ってない」

という印象になります。

信用度がかなり上がります。

---

### ② 契約率が上がる

例えば

```
ホームページ制作

29,800円

＋

ドメイン

4,980円

＋

SSL

3,000円

＋

管理費

5,000円
```

みたいな会社は多いです。

EnterpriseOSでは

```
Company Growth

9,800円

+

ドメイン

実費だけ
```

になります。

かなり分かりやすいです。

---

### ③ SaaSを売りたい

あなたが売りたいのは

```
Company Growth
```

です。

ドメインではありません。

だから

```
ドメイン

利益0円

↓

Company Growth

利益率80〜90%
```

の方がビジネスとして強いです。

---

# Stripeではどうなる？

Stripeには

```
Product

Company Growth
```

があります。

そこへ

```
9800円/月
```

を登録しています。

一方、

ドメインは

```
Product

Domain Registration
```

のような固定価格商品にはしません。

購入直前に

```
OpenProvider API

↓

現在価格取得

↓

Stripe Checkoutへ渡す
```

という流れになります。

つまり

```
OpenProvider

↓

.com

1,623円

↓

Stripe

1,623円

↓

決済
```

です。

価格を固定しないので、

為替変動にも対応できます。

## ただし1つ気になる点があります

現在の仕様では

```
ドメイン原価

+

Stripe手数料

+

為替差額

=

EnterpriseOS負担
```

になっています。

例えば

```
原価

1,600円

Stripe手数料

70円

為替差

30円

合計

1,700円

↓

販売

1,600円
```

すると100円の赤字になります。

これが数千件になると無視できません。

### 私ならこう設計します

「利益」は乗せませんが、**実費**は回収します。

```
ドメイン料金

＝

OpenProviderの最新価格
＋
Stripe決済手数料
＋
為替手数料
```

これなら、

- ドメイン自体では利益を取らない
- しかし赤字にもならない
- 「実費のみ」という説明も維持できる

というバランスになります。

## さらに発展させるなら

EnterpriseOSには将来的に以下も追加できます。

- **Domain Search**：空きドメイン検索
- **Domain Suggestions**：AIによる候補提案
- **Domain Intelligence**：ブランド性・SEO・発音・商標リスクをスコアリング
- **One-click Purchase**：検索からStripe決済、OpenProvider登録までワンクリック
- **Auto Renewal**：更新日の自動通知とワンクリック更新

これらを **BrandForge Intelligence** と連携させれば、「社名決定 → 商標確認 → ドメイン取得 → 会社サイト公開」までを一つのフローで提供できるようになり、EnterpriseOSの大きな差別化要素になります。
