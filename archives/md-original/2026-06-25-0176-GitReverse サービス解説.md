GitReverseは、**GitHubリポジトリを読み取り、「このアプリをAIに作らせるなら、どんなプロンプトになるか」に変換するサービス**です。

つまり普通のリバースエンジニアリングというより、**コード → 設計意図 → AI開発用プロンプト**に戻すツールです。

公式GitHubによると、取得する主な情報は「リポジトリのメタデータ、ルートのファイルツリー、README」で、それをLLMに渡して、Cursor / Claude Code / Codex などに貼れる短い自然文プロンプトを生成します。citeturn382150view0

### できること

GitHub URLを入れると、そのリポジトリをもとに、

「こういうアプリを作って」
「こういう機能を入れて」
「こういう技術構成で」
「こういうUI/UXにして」

という**再開発用プロンプト**を出します。

例えるなら、完成品のコードから「元の発注書」や「AIへの指示文」を推測するサービスです。

### 使い方

GitHub URLを貼るか、`owner/repo`形式で入力します。さらに、GitHub URL内の `hub` を `reverse` に置き換える使い方も案内されています。citeturn229902search0

### 無料版と有料版

無料の **Quick reverse** は軽い分析用。有料のPremiumは月額9ドルで、月5回の **Deep reverse** と月5回の **Manual control** が使えます。Deep reverseはコードベースのアーキテクチャや設計理由まで掘る機能、Manual controlは特定機能やワークフローに絞って逆解析する機能です。citeturn382150view1

### 技術構成

GitReverse自体もOSSで、Next.js 16、React 19、TypeScript、Tailwind CSS、GitHub API、Supabase、Stripeなどで作られています。LLMプロバイダはGrok、OpenRouter、Azure OpenAI、Google AI Studioに対応しています。citeturn382150view0

### 誰向けか

主な対象は、開発者、バイブコーダー、技術系Founderです。公式スポンサー説明でも「既存コードベースを理解・コピー・拡張したい開発者」が利用者だと説明されています。citeturn382150view2

### 率直な評価

便利ですが、**“コードを完全に解析して同じものを再現する魔法”ではありません**。READMEと浅いファイル構造からプロンプト化するため、Quick reverseだけでは内部実装・DB設計・認証・例外処理・細かいUXまでは落ちやすいです。

使いどころは明確です。

**良い用途**
既存OSSの構想把握、類似アプリの仕様書化、Codex/Claude Code用の初期プロンプト作成、競合サービスの構造理解。

**危ない用途**
ライセンス無視の丸パクリ、商用コードの無断複製、セキュリティ系リポジトリの攻撃目的利用。

## ただし、注意点があります

ここは冷静に見る必要があります。

GitReverseの出力をそのまま大量収集して販売するのは、**サービス規約や著作権・ライセンスの確認が不可欠**です。また、OSSごとにライセンス条件（MIT、Apache-2.0、GPLなど）が異なるため、コードやREADMEの再配布には注意が必要です。

そのため、**生データを売るのではなく、自分で解析・構造化したメタデータや設計知識、比較情報、生成プロンプトを提供する形**のほうが、独自性も高く、法的にも設計しやすいでしょう。

私なら、「GitReverseの結果を集めるサービス」は作りません。代わりに、**AI開発者向けの「設計検索エンジン」**として、機能・アーキテクチャ・DB・API・UI・プロンプトを横断検索できるサービスを目指します。これは既存のUIギャラリーとは競合せず、AI時代ならではの価値を提供できます。

## SaaS化の落とし穴

よくある失敗は、

> GitReverseをWebアプリにした

だけです。

これはユーザーから見ると、

- GitReverseがある
- ChatGPTがある
- Claude Codeがある
- Codexがある

ので、**「わざわざ月額を払う理由」が弱い**です。

つまり、SaaSという形態にしたこと自体には価値がありません。

3. **Codex・Claude Code向け実装パック**を追加する。

5. チーム向け機能（共有・ナレッジ蓄積・ガバナンス）を追加して月額課金を拡大する。
