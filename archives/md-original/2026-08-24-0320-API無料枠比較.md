# 3. DeepSeekがかなり面白い

ここは前回答の計算も訂正します。

現在の urlDeepSeek API公式料金turn0search0 ではDeepSeek-V4-Flashが、

- Input cache miss：$0.14 / 100万tokens = **約0.0022万円**
- Input cache hit：$0.0028 / 100万tokens
- Output：$0.28 / 100万tokens = **約0.0045万円**

です。citeturn0search0

したがって、

> 「月30,000 DeepResearch = $42」

とは単純には計算できません。

**リサーチ1件あたり何token投入して何token生成するか**で大幅に変わります。

例えば仮に1リサーチについて、

- Webから取得した本文：20,000 input tokens
- Graph/Ontology等：3,000 output tokens

とすると、キャッシュなしでも、

`20,000 × $0.14/M + 3,000 × $0.28/M`

= 約 **$0.00364/件**

30,000件なら、

**約$109 = 約1.73万円/月**

程度です。

これは相当に安い。

## 7. Gemini / OpenRouter / DeepSeekの役割を分ける

全部を競合として考えない方がいいです。

**Gemini Search Grounding**  
→ Google検索を伴う結果の品質比較・教師データ

**自社SERP**  
→ 大量の生検索データ取得

**DeepSeek V4 Flash**  
→ 大量データの安価な構造化・分類・Graph生成

**OpenRouter無料モデル**  
→ 別モデルによるValidation / Cross-check

と役割分担できます。

たとえばDeepSeekが抽出したKnowledge GraphをQwen/Nemotron等に再判定させる。

2モデル一致：

`confidence = HIGH`

不一致：

`confidence = REVIEW`

とする。

これなら無料/超低価格LLMを使うこと自体が、**データ品質向上機構**になります。
