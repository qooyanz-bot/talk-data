## 何が起きているのか

画面上部の

> Thundering... (6m 31s)

は、Claude が何らかの処理を実行中であることを示しています。

通常なら途中で

```text
Claude、これについて教えて
```

と話しかけると、

- 現在のタスクを中断
- 新しい会話に切り替え

になる可能性があります。

そこで `/btw` を使うと、

```bash
/btw npm install が失敗している原因は何？
```

のように、**今の作業とは別の軽い質問**を投げられます。

Claude は

- メインタスクを継続
- サイド質問だけ回答

を行います。

---

## 「btw」の意味

`btw` は

> By The Way

の略です。

日本語なら

> ところで

に近いニュアンスです。

---

## 実際の使いどころ

例えば Claude に

```text
Next.jsアプリをリファクタリングして
```

を依頼していて作業中に、

```bash
/btw useMemo と useCallback の違いは？
```

と聞けます。

または

```bash
/btw 現在変更しているファイル一覧を教えて
```

```bash
/btw 今何をしている？
```

など。

---

## Claude Codeで便利な理由

AIコーディングでは

- 長時間の修正
- テスト実行
- 大規模リファクタリング
- エージェント実行

が数分続くことがあります。

その間に

```text
今の作業を止めずに質問したい
```

という需要があり、そのためのコマンドが `/btw` です。

感覚としては

- 通常の入力 → 「仕事を切り替える」
- `/btw` → 「横から一言聞く」

という違いです。

Claude Codeを使い込むなら、`/btw` は意外と使用頻度が高いスラッシュコマンドの一つです。特に長時間エージェント実行中の確認や雑談的な質問に便利です。
