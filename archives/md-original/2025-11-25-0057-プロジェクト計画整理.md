# 要約（エグゼクティブサマリ）
GTM社におけるNFF（No Fault Found）返品は、返送品の約30%を占め、年間で「数億円」規模の不要コストを生んでいる。本プロジェクトの最重要攻略対象はこのNFF削減であり、AIは単なる検索ツールではなく「オペレーターの診断を支援して不要返品を未然に防ぐ防波堤」として設計すべきである。NFF削減が達成できれば物流費・検査人件費・在庫評価減だけでなく、顧客満足度回復による二次コスト低減も見込め、経営目標の「CSコスト20%削減」達成に直結する。

# NFFによるコスト構成（概念モデル）
NFF一件あたりに発生する主要コスト項目  
- 物流（往復送料）  
- 検品・再現試験にかかる技術者人件費（通常検査より時間が長い）  
- 再販価値の低下（新品→リファービッシュ）または廃棄による在庫評価減  
- 二次問い合わせ／再返品による追加CSコスト（顧客満足度低下の波及）  

これらを合算した**一件当たりコスト（C）**を用いて損失総額を算出するモデル：  
```
年間NFF件数 = 年間返品総数 × NFF率
年間NFFコスト = 年間NFF件数 × C
```
（実運用では「検査時間」「平均送料」「平均評価減額」等を細分化して算出することを推奨）

### 参考の簡易例（説明用）
（※実数値はGTM社の実績値で置き換えてください）  
- 年間返品総数 = 10,000 件  
- NFF率 = 30% → 年間NFF件数 = 3,000 件  
- 一件当たりコスト C = ¥22,000（往復送料 ¥2,000 + 検査人件費等 ¥5,000 + 評価減 ¥15,000）  
- 年間NFFコスト = 3,000 × 22,000 = ¥66,000,000（6,600万円）  

AIでNFF率を仮に50%削減できれば：削減件数 = 1,500 件、削減金額 = 1,500 × 22,000 = ¥33,000,000。  
→ この例だけでも大きなROIが見込める（ただし実数値は要精査）。

# 測定指標（KPI） — トライアルで必須の計測項目
必須KPI：  
- NFF率（返品総数に対するNFFの割合）  
- NFF一件当たり平均コスト（物流、検査時間、評価減）  
- NFF件数の相対削減率（対前期間比）  
- 一次解決率（FCR：First Contact Resolution）  
- AHTへの影響（AI導入で短縮／延長がどの程度か）  
- 顧客CSAT（返品関連の再発率、満足度変化）  
- オペレーターの利用率・エビデンス遵守率

優先度高：NFF率、NFF一件当たりコスト、FCR、オペレーター証跡遵守率
