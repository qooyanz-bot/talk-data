「キャッシュ」は、簡単に言うと「次回高速に動かすための使い捨てデータ」です。

あなたのPCでは、AI開発やCodex、Node.jsを使っているため、一般的なPCよりキャッシュがかなり多くなっています。

### 1. pnpm-cache（約0.5GB）

場所
```
C:\Users\user\AppData\Local\pnpm-cache
```

これは `pnpm`（Node.jsのパッケージマネージャー）がダウンロードしたライブラリを保存している場所です。

例えば

```
npm install react
```

を実行すると、

```
react
typescript
vite
...
```

など数百〜数千のパッケージをダウンロードします。

毎回インターネットから取得すると遅いため、

```
pnpm-cache
```

に保存して再利用します。

### 削除しても大丈夫？

はい。ほぼ問題ありません。

削除すると

- プロジェクトは壊れない
- 次回 `pnpm install` のときに再ダウンロードされる
- 初回だけ少し時間がかかる

だけです。

---

### 2. Chromeキャッシュ（約0.3GB）

場所

```
C:\Users\user\AppData\Local\Google\Chrome\User Data\Default\Cache
```

Chromeが

- 画像
- JavaScript
- CSS
- フォント

などを保存しています。

例えば

```
https://openai.com
```

へ何度もアクセスすると、

ロゴ画像などを毎回ダウンロードせず、

```
Cache
```

から読み込みます。

削除しても

- ブックマーク
- パスワード
- 履歴

は消えません。

最初の表示だけ少し遅くなります。

---

### 3. Temp（一時ファイル）

場所

```
C:\Users\user\AppData\Local\Temp
```

ここには

- インストーラー
- 解凍途中ファイル
- AI生成時の一時データ
- ブラウザ一時データ

などが入っています。

例えば

```
ZIPを解凍
```

すると

```
Temp
```

へ展開してから本来の場所へコピーされます。

途中で残ったゴミが大量にあります。

これは古いものなら削除して問題ありません。

---

### 4. uv Cache（Python）

Python開発をしている場合

```
uv cache
```

があります。

AIライブラリ

```
numpy
torch
transformers
```

などを保存しています。

これも

```
uv cache clean
```

で消せます。

必要になれば再ダウンロードされます。

## 削除してはいけないもの

以下は「キャッシュ」ではなく、開発環境そのものや重要なデータなので、直接削除するのは避けてください。

- `.claude`（約13GB）
- `.codex`（約6.5GB）
- `AppData\Local\wsl`
- `AppData\Local\Packages`
- `company2_all.jsonl`（企業DB）

これらを消すと、設定やモデル、開発環境、業務データに影響が出る可能性があります。

あなたのようにCodex・Claude・Node.js・Pythonを頻繁に使う環境なら、月に1回程度、各種キャッシュを整理するだけでも数GBの空き容量を維持しやすくなります。
