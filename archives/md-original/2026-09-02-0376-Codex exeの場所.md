Windows版Codexの `codex.exe` なら、現在の構成では主にここです。

```text
C:\Users\<ユーザー名>\AppData\Local\OpenAI\Codex\bin\<バージョン/ハッシュ>\codex.exe
```

実例として、Windows版では次の場所が確認されています。citeturn0search8turn0search10

```text
C:\Users\Administrator\AppData\Local\OpenAI\Codex\bin\fb2111b91430cb17\codex.exe
```

### 一発で探す

PowerShellでこれを実行するのが確実です。

```powershell
Get-ChildItem "$env:LOCALAPPDATA\OpenAI\Codex" -Filter "codex.exe" -Recurse -ErrorAction SilentlyContinue |
    Select-Object -ExpandProperty FullName
```

また、Microsoft Store/MSIXパッケージ内にも、

```text
...\WindowsApps\OpenAI.Codex_<version>_x64__2p2nqsd0c76g0\app\resources\codex.exe
```

があります。ただし、**直接使うならWindowsApps内ではなく `%LOCALAPPDATA%\OpenAI\Codex\bin\...` 側を推奨**します。Codex Desktop自身もパッケージ内の `codex.exe` をユーザー側ランタイムディレクトリへ配置する仕組みを使っています。citeturn0search0

なお、2026年9月現在はCodexアプリが新しいChatGPT Desktopへ統合されつつあり、GUI本体と内部の `codex.exe` は別物です。citeturn0search3turn0search5

**Cortext9から直接Codex CLIを呼びたい**のであれば、上のPowerShell結果を貼ってください。どの `codex.exe` を固定すべきか判定できます。memcite

はい。**CLI の `codex.exe` ではなく、GUIの「Codex Desktop」本体を探したい**ということですね。

現在は仕様が変わっており、Windows版の旧 **Codex Desktop は新しい ChatGPT Desktop に統合**されています。Codex はそのアプリ内の独立画面として動作します。citeturn0search2turn0search1

まずPowerShellでこれを実行してください。

```powershell
Get-AppxPackage *OpenAI* | Select-Object Name, PackageFullName, InstallLocation
```

さらに、実際の `.exe` を探すなら：

```powershell
Get-AppxPackage *OpenAI* | ForEach-Object {
    Get-ChildItem $_.InstallLocation -Filter "*.exe" -Recurse -ErrorAction SilentlyContinue |
    Select-Object FullName
}
```

**結果をそのまま貼ってください。**  
こちらで、

**① Codex Desktop/新ChatGPT Desktop本体 → ② 起動用EXE → ③ 内部のcodex.exe**

を区別して、どれを直接起動すればいいか特定します。

なお、現在の公式仕様では「ChatGPT Desktop → 左上メニュー → Codex」で旧Codex Desktop相当の画面に入ります。citeturn0search3

見つかっています。**Codex Desktop 本体はこれです。**

```text
C:\Program Files\WindowsApps\OpenAI.Codex_26.825.6671.0_x64__2p2nqsd0c76g0\app\Codex.exe
```

一方で、

```text
...\app\resources\codex.exe
```

は **Codex CLI / 内部実行エンジン側** です。GUIアプリ本体ではありません。

起動確認だけなら PowerShell で：

```powershell
Start-Process "C:\Program Files\WindowsApps\OpenAI.Codex_26.825.6671.0_x64__2p2nqsd0c76g0\app\Codex.exe"
```

ただし `WindowsApps` 配下は権限が特殊なので、**ショートカット作成や他プログラムから安定して起動する用途では、AppUserModelID 経由の起動の方が安全**です。

まずこれでパッケージ名を確認できます。

```powershell
Get-StartApps | Where-Object { $_.Name -match "Codex|ChatGPT" }
```

結果を貼ってもらえれば、**Codex Desktop を1行で起動できる PowerShell コマンド**まで正確に作れます。
