## 1) まず競合が強い“土俵”を確認（正面衝突は負け筋）
競合上位は、だいたいこの3点で殴ってきます。

- **品揃え（常時ラインナップ大量）×アプリ通知×SNS拡散**  
  例：DOPAは公式で「豊富なラインナップ」を強く訴求し、アプリも展開。 citeturn2search0turn2search4  
- **インフルエンサー/コラボ×多ジャンル展開**  
  例：Cloveは公式でインフルエンサーコラボや多数ジャンルを打ち出し。 citeturn2search1turn2search9  
- **配送スピード訴求（“最短翌日”など）×プッシュ通知**  
  例：日本トレカセンターのアプリ説明は配送スピードと通知を前面に。※公称表現として捉える。 citeturn2search23  

ここに広告費で真正面から殴り合うと、規模差でしんどいです。

## 2) アイリストレカの勝ち筋は「信頼 × オペ精度 × オムニチャネル」の3本柱
アクセルマーク側の資料でも、**店舗・自販機・EC・オリパサイトを繋いだオムニチャネル**と、購買データを使った企画・在庫効率・UI/UX向上・コミュニティ形成が明示されています。 citeturn6view0turn6view1  
つまり、勝ち筋は “ネットオリパ単体” ではなく **「体験と信頼の総合力」**に置けます。

### 柱A：信頼で勝つ（業界最大のボトルネック）
オリパ市場は「当たる/当たらない」より前に、ユーザーが不安になるのが**透明性・表示・対応**です。景表法は“射幸心そのもの”を規制するというより、**不当表示や誤認表示**が問題になりやすい領域。 citeturn4search1turn4search2  
**やること（差別化になる順）**
1. **“見える化”を標準装備**  
   - 当たり枠の「残数」や「出た履歴」を、ユーザーが検証可能な形で提示（※表現は法務レビュー前提）  
2. **第三者目線の監査っぽさ**（本当に監査するかはコスト次第）  
   - 高額帯オリパだけでも「封入設計・在庫管理・出庫」プロセスを説明ページ化  
3. **安心機能（責任ある利用）**  
   - 自己上限設定、利用履歴の見える化、年齢確認導線など（炎上耐性が上がる）

> ポイント：これはマーケではなく“運営設計”なので、真似されにくいです。

### 柱B：オペ精度で勝つ（配送とCSが最強のLTVレバー）
アイリストレカは小規模ゆえ改善を回してきた、という採用広報上の示唆があります。 citeturn0search13  
ここを「速度」ではなく **“予測可能性”**で勝つのが効きます。

**やること**
- **発送SLAを分解して約束する**  
  - 例：「発送依頼→検品完了：24h以内」「検品→出庫：48h以内」など、工程別に可視化  
- **CSの一次回答を早くする（テンプレではなく状況反映）**  
  - ステータス画面に“今詰まってる理由”を出すだけで問い合わせが減ります  
- **梱包品質の標準化（撮影ログ）**  
  - 高額カードは出庫前撮影＋封緘ログ（紛争コスト削減）

### 柱C：オムニチャネルで勝つ（“オンラインだけ”を脱出）
資料上、店舗・自販機・EC・オリパのデータ連携での拡大が戦略として語られています。 citeturn6view0turn6view1  
**この土俵は大手ネットオリパ全員が得意ではない**ので、ここが最大の堀になります。

**やること**
- **店舗/イベント連動オリパ**（オフライン限定の体験をオンラインに還流）
  - 店舗来店で限定オリパ解放、逆にオンラインで当てたカードを店舗で受け取れる等  
- **自販機/店舗の“購買データ”をオリパ設計に反映**
  - 地域/客層で刺さるラインナップを変える（在庫回転も上がる）

## KPIツリー（粗利 → LTV → 施策）

### 0) ゴール定義（週次で見る“粗利”はこれ）
**週次 粗利（≒貢献利益）**  
= **週次 売上（ネット）**  
− **景品原価（当たりカードの原価/仕入）**  
− **発送・梱包費**  
− **決済手数料**  
− **返金・チャージバック・補填**  
− **CS/運営の変動費（外注/人件費の可変分）**

> まずは固定費を除いた“貢献粗利”で週次を回すのが安定します（固定費は月次でOK）。

---

### 1) 粗利の分解ツリー

```
粗利
├─ 売上（ネット）
│   ├─ アクティブ課金者数（週次）
│   │   ├─ 新規課金者数
│   │   │   ├─ 新規流入数
│   │   │   └─ 初回課金CVR（登録→課金）
│   │   └─ 既存課金者数（リピート）
│   │       ├─ リピート率（前週課金→今週も課金）
│   │       └─ 休眠復帰率（○週未課金→復帰）
│   └─ 1人あたり売上（ARPPU/週）
│       ├─ 平均購入単価（1回あたり）
│       └─ 購入回数（頻度）
├─ 変動費
│   ├─ 景品原価率（原価/売上）
│   │   ├─ 高額当たりの放出量
│   │   ├─ 仕入単価（相場/調達力）
│   │   └─ 在庫回転（滞留→評価損の予兆）
│   ├─ 物流費率（送料+梱包/売上）
│   │   ├─ 発送件数（当選・交換・出庫）
│   │   └─ 1件あたり物流費（契約/梱包品質）
│   ├─ 決済費率（手数料/売上）
│   └─ 返金・補填率（返金+補填/売上）
│       ├─ 不着/破損
│       ├─ 誤発送
│       └─ 期待不一致（表示・体験）
└─ 粗利率
    ├─ 単価帯ミックス
    ├─ 商品設計（最低保証・演出ではなく、設計）
    └─ 信頼（クレーム/返金/否認の抑制）
```

---

### 2) LTV（貢献利益）ツリー：粗利の“将来分”を握る

**LTV（貢献利益ベース）/ユーザー**  
= Σ（期間tの **売上/人 × 粗利率** ） − **獲得コスト（CAC）**  
※実務では「コホート別のD7/D30/D60累計貢献粗利」で追うのが一番ブレません。

```
LTV（貢献利益）
├─ 収益（累計）
│   ├─ 初回（D0〜D7）
│   │   ├─ 初回課金CVR
│   │   └─ 初回ARPPU
│   └─ 継続（D8〜）
│       ├─ リテンション（D7/D30/D60）
│       ├─ 購入頻度（週あたり回数）
│       └─ 単価（平均購入単価）
├─ 粗利率（累計）
│   ├─ 景品原価率
│   ├─ 物流費率
│   ├─ 決済費率
│   └─ 返金・否認率
└─ CAC（獲得コスト）
    ├─ 広告CPA
    ├─ 紹介インセンティブ
    └─ コラボ/施策コスト（按分）
```

### 3) 施策 → どのKPIを動かすか（直結マッピング）

**A. 新規課金者を増やす（売上↑ / LTV入口↑）**  
- 施策：LP改善、初回限定オリパ、LINE導線最短化  
- 動かすKPI：新規流入 → 登録CVR → 初回課金CVR → 初回ARPPU

**B. リピートを増やす（LTV本体↑）**  
- 施策：週次の固定編成（低単価デイリー/週次目玉/月次祭り）、ミッション、復帰オファー  
- KPI：D7/D30、前週課金→今週課金、2回目購入までの日数、購入頻度

**C. 粗利率を守る（同じ売上でも粗利↑）**  
- 施策：原価率の上振れ抑制（放出設計・仕入）、物流の単価最適化、決済否認の低減  
- KPI：景品原価率、物流費率、返金率、チャージバック率、誤発送率

**D. 信頼を上げる（返金/否認↓、復帰↑、紹介↑）**  
- 施策：残数/履歴の“見える化”、発送SLAの見える化、CS一次回答スピード、出庫前撮影ログ（高額のみでも）  
- KPI：問い合わせ率、返金率、否認率、SNSネガ比率（可能なら）、NPS/満足度

## 週次の運営ダッシュボード項目（そのまま運用会議で使える）

### 1) 経営サマリー（3分で全体判断）
- **売上（ネット）**：週次 / 前週比 / 4週移動平均  
- **粗利（貢献利益）**：週次 / 粗利率  
- **新規課金者数 / 既存課金者数**：構成比  
- **返金・否認（チャージバック）金額と率**：異常検知の最優先

---

### 2) 獲得（CACを含めて“質”を見る）
- **流入数（チャネル別）**：広告 / SNS / 紹介 / 直  
- **登録CVR**：LP→登録  
- **初回課金CVR**：登録→7日以内課金  
- **CAC / 新規課金者（チャネル別）**  
- **新規コホートのD7累計貢献粗利（暫定LTV）**：広告の当たり外れが一発で分かる

---

### 3) マネタイズ（売上の中身）
- **週次課金者数（WA-Payers）**  
- **ARPPU（週）**  
- **平均購入単価** と **購入頻度（回/週）**  
- **商品ミックス**：低/中/高単価帯の売上構成比  
- （可能なら）**2回目購入までの中央値日数**：中毒性の指標

---

### 4) リテンション（LTVの根）
- **D1 / D7 / D30 リテンション（新規コホート別）**  
- **リピート率（前週課金→今週課金）**  
- **休眠復帰率（例：4週未課金→今週課金）**  
- **累計貢献粗利/ユーザー（D7/D30）**：LTVを“推定”じゃなく“実測”で追う

---

### 5) 原価・在a（粗利率を守る防波堤）
- **景品原価率（週）**：当たり放出の影響が出る  
- **高額当たり放出数 / 週**：原価率の先行指標  
- **仕入単価指数（主要カードの平均との差）**：調達力の見える化  
- **在庫回転（日数）**：滞留＝将来の評価損・資金圧迫の予兆

---

### 6) 物流（体験とコストの交点）
- **発送件数**（当選・交換・出庫）  
- **発送リードタイム**：平均とP95（遅い尻尾が炎上を作る）  
- **SLA達成率**（例：48h以内出庫率）  
- **1件あたり物流費**：送料＋梱包材＋作業  
- **破損/不着率**：補填コスト直結

---

### 7) CS・信頼（返金/否認を未然に潰す）
- **問い合わせ率（件/課金者 or 件/発送）**  
- **一次回答時間（中央値）** / **解決までの時間**  
- **誤発送率**（件/発送）  
- **返金率**（金額/売上）  
- **チャージバック率**（件数・金額/売上）  
- **重大インシデント件数**：表示ミス、残数不整合、在庫欠品での代替対応など

---

### 8) ポイント/負債（オリパ特有：資金繰りを守る）
- **未消化ポイント残高（負債）**  
- **ポイント購入→消化（開封）率**  
- **高額景品の未発送残**（出庫滞留）  
- **換金性の高い景品比率**（リスク管理）

---

## 運用のコツ（週次会議の型）
