### なぜ危険なのか

今回の `.env.local` には以下のような情報が含まれています。

- `OPENAI_API_KEY`
- `FIRECRAWL_API_KEY`
- （将来）`VERCEL_TOKEN`
- `MORPH_API_KEY`

これらは**パスワードと同じ**です。

もし第三者が取得すると、

- あなたのOpenAIアカウントでAPIを大量利用される
- 高額請求される
- Firecrawlを勝手に使われる
- Vercelへデプロイされる
- Sandboxを勝手に起動される

ということが起こります。

## ローテーションとは

ローテーションとは

> 古いキーを無効化して、新しいキーを作る

ことです。

例えば

```
古いキー

sk-proj-AAAA

↓

削除

↓

新しいキー

sk-proj-BBBB
```

これだけです。

## Vercelではどうする？

本番環境では

```
.env.local
```

をアップロードしません。

代わりに

Vercel Dashboard

```
Settings

↓

Environment Variables
```

へ登録します。

するとサーバー側だけが見られます。

これが正式な運用方法です。

---

## あなたのBuilderOSやDealVaneを開発するなら

今後プロジェクトが大きくなるので、次の運用を強くおすすめします。

- **ローカル開発**: `.env.local` にAPIキーを保存（Git管理外）
- **GitHub**: APIキーは一切コミットしない
- **Vercel**: Environment Variables に登録
- **開発メンバー**: 各自が自分の `.env.local` を持つ
- **キー漏洩時**: 即座にローテーション（古いキーを無効化し、新しいキーへ差し替え）

この運用にしておけば、BuilderOSやDealVaneのようなプロダクトでも安全性を保ちながら開発を進められます。
