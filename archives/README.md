# 会話アーカイブ

公開済み会話の保存先。会話で述べられた内容は、ここへ保存しただけでは正本の決定・観測事実・Future Conceptの最終版にならない。採用する定義や決定は、所定の各カテゴリ文書と changelog に別途記録する。

## 2026-09-06 ChatGPT export

- 範囲: 380会話、17,957メッセージ（2024-11-08〜2026-09-04 UTC）
- ファイル: `2026-09-06/chatgpt-export-sanitized.jsonl.gz`
- 形式: 1会話を1行のJSONとしてgzip圧縮。本文、話者、作成時刻、タイトルのみを保持する。
- 除外: セッションIDなどのメタデータ、添付ファイル本体。
- 不可逆置換: 秘密形式、メールアドレス、電話番号。詳細とハッシュは同ディレクトリの `manifest.json` を参照。

元のHTMLを公開リポジトリへ置かない。`manifest.json` の source SHA-256 は、入力ファイルが同一か確認するための照合値であり、原本の再配布先ではない。
